# x402-демо (S6-05, testnet-only)

> Демонстрация платного доступа по протоколу **x402** (HTTP 402 + EIP-3009-подпись).
> **Демо-режим:** тестнет Sepolia, собственный токен **xUSDC** (`0x0eB3e17862A108Bbbc91989e6Ca1a3ed16f69710`) без ценности.
> Реальный приём платежей (INTL-профиль) — STOP-GATE (решение владельца; 282-ФЗ: крипта ≠ средство платежа внутри РФ).

## Поток

```
Клиент GET /api/v1/x402/demo/premium
  ← 402 + payment requirements (scheme exact, network sepolia, asset xUSDC, payTo, price)
Клиент подписывает EIP-712 TransferWithAuthorization (EIP-3009) своим ключом
Клиент повторяет GET с заголовком X-PAYMENT: base64(payload)
  → сервер: верификация подписи (ecrecover) + параметров (payTo/сумма/срок/nonce)
  → сеттлмент: сервер отправляет transferWithAuthorization (газ сервера)
  ← 200 + контент + X-PAYMENT-RESPONSE: base64(receipt {tx_hash, payer, amount_wei})
Повтор той же подписи → 402 NONCE_USED (контракт помнит использованные nonce)
```

## Запуск демо

```bash
# сервер (karta-dev) должен быть запущен
backend/.venv/bin/python scripts/x402_demo_client.py
```

Демо-плательщик: `KARTA_X402_DEMO_PAYER_KEY` в `~/.env` (одноразовый тестнет-кошелёк; пополняется `mint`).

## Честные ограничения

- Это **демо**: контент — заглушка «здесь был бы платный ответ KARTA»; токен без ценности.
- Facilitator не используется: верификация локальная, сеттлмент сервер платит газ.
- Реальный x402 (USDC на Base, facilitator, INTL-клиенты) — отдельное решение и бюджет.
