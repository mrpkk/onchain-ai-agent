# KARTA — term sheet outline (licence or asset purchase)

**Назначение:** чтобы при первом «да» не начинать с нуля. Это остов, не юридический документ:
финальные формулировки — с юристом, когда появится контрагент (`LEGAL REVIEW REQUIRED`).

## 1. Что продаётся

| Пакет | Что входит | Ориентир |
|---|---|---|
| **White-label licence** | hosted control plane под брендом покупателя, 1 год, поддержка интеграции, без исходников | **$25 000 / год** |
| **Perpetual licence (non-exclusive)** | исходники, право встраивать, 12 месяцев обновлений, без перепродажи как отдельного продукта | **$50 000–150 000** |
| **Asset purchase / acqui-hire** | код, тесты, домены `karta.rta.lat`, бренд, документация, основатель на 90 дней | **$150 000–1 000 000** |

Не входит ни в один пакет: токен, кастоди, приём чужих средств, обязательства по SLA сверх
записанного ниже.

## 2. Что покупатель получает фактически

- 406 автотестов, 4 сценария демо, 3 воспроизводимые атаки, проверяемые одной командой;
- политика E01–E08 (детерминированная, без LLM в решающем звене);
- атомарный бюджет: 100 параллельных запросов при 50 × $0.05 → ровно 50 разрешений;
- kill switch < 2 с, evidence-пакет с Ed25519, проверка без нашего сервера;
- x402-guard, MCP-сервер, публичный API, документация установки (10 минут);
- 3 лицензии на сторонние компоненты проверены: FastAPI/BSD, cryptography/Apache-2.0, web3/MIT.

## 3. Ключевые условия (обязательные)

| Условие | Наша позиция |
|---|---|
| Эксклюзив | только за отдельную плату и только на срок; по умолчанию non-exclusive |
| Оплата | USDC на Base, 50 % при подписании, 50 % при передаче; либо 100 % на эскроу с раскрытием по приёмке |
| Приёмка | 10 рабочих дней: покупатель запускает атаки и тесты на своей машине; не прошло — возврат |
| IP | передаётся/лицензируется «как есть»; сторонние компоненты — по их лицензиям |
| Ответственность | ограничена суммой договора; никаких «100 % безопасности» и гарантий прибыли |
| Гарантия | 30 дней исправления дефектов, найденных при приёмке |
| Публичность | покупатель вправе не упоминать сделку; мы не публикуем без письменного согласия |
| Юрлицо | сейчас физлицо РФ; для контракта с компанией потребуется структура — это отдельный шаг и отдельные сроки |

## 4. Чего в сделке не будет

- Токена, токен-варрантов, «будущих процентов от протокола».
- Кастоди или прохождения клиентских средств через нас.
- Обещаний SLA 99,9 % без инфраструктуры, которая это выдержит.
- Продажи клиентских данных: их у нас нет.

## 5. Что нужно от покупателя до term sheet

1. Один технический человек на 60 минут: прогнать тесты и атаки на своей машине.
2. Ответ на один вопрос: покупается **функция** (лицензия) или **команда и актив** (acqui-hire).
3. Имя юрлица-покупателя и кто подписывает.

## 6. Честная оговорка

Выручки нет, платящих нет. Оценка строится на активе — работающем коде, тестах, доказательствах,
домене и авторе, — а не на P&L. Если покупатель считает иначе, это нормально: тогда разговор
идёт о пилоте за $2 500, а не о лицензии.
