# Kwork — On-Chain AI Agent Framework

## Название кворка
Разработка автономного AI-агента для блокчейна (смарт-контракты, DeFi, трейдинг)

## Категория
Разработка и IT → Программирование

## Описание

Создам **автономного AI-агента**, который работает на блокчейне 24/7 без вашего участия.

### Что умеет агент:

- **Владеет кошельком** — управляет средствами на Ethereum/BSC/Polygon
- **Заключает смарт-контракты** — автоматически исполняет сделки по условиям
- **Оптимизирует доходность** — ищет лучшие DeFi-протоколы (Aave, Compound, Uniswap)
- **Делает арбитраж** — находит спреды между сетями и биржами
- **Ricardian-контракты** — юридически обязывающие соглашения + код
- **Безопасность** — лимиты расходов, kill switch, режим симуляции

### Стек:
- Python + FastAPI (backend)
- Web3.py (интеграция с блокчейном)
- Solidity + Hardhat (смарт-контракты)
- Mistral AI (принятие решений)
- Docker (деплой)

### Что получите:
- Готовый фреймворк с API
- 3 смарт-контракта (Ricardian Agreement, Agent Registry ERC-8004, Escrow)
- Веб-дашборд для мониторинга
- Docker-Compose для запуска
- Документация + инструкция

### Примеры использования:
- Автоматический трейдинг по AI-стратегиям
- Управление казначейством DAO
- Исполнение контрактов между компаниями
- Yield farming без ручного контроля

**Срок:** 7-14 дней
**Цена:** от 50 000 ₽

# Kwork — Telegram AI-бот с RAG

## Название кворка
Разработка Telegram-бота с AI (RAG-система, база знаний, админ-панель)

## Категория
Разработка и IT → Программирование

## Описание

Создам **Telegram-бота с AI**, который отвечает на вопросы по вашим документам.

### Как работает:
1. Вы загружаете PDF/документы в бота
2. Клиент задаёт вопрос в Telegram
3. Бот **мгновенно отвечает** из вашей базы знаний
4. Если вопрос не из базы — использует AI (Mistral)

### Возможности:
- **RAG-система** — точные ответы из ваших документов
- **FAQ** — быстрые ответы на частые вопросы
- **Админ-панель** — управление документами, FAQ, аналитика
- **Обратная связь** — кнопка "Полезно?" для улучшения качества
- **Статистика** — количество вопросов, точность, популярные темы

### Стек:
- Python + FastAPI
- Telegram Bot API
- Mistral AI (LLM + Embeddings)
- ChromaDB (векторная база)
- Streamlit (админ-панель)
- Docker

### Для кого:
- интернет-магазины (ответы на вопросы о товарах)
- онлайн-школы (поддержка учеников)
- компании (внутренняя база знаний)
- медицинские/юридические фирмы (ответы по документам)

**Срок:** 3-5 дней
**Цена:** от 15 000 ₽
